# Privacy Policy

Last updated: November 25, 2026

MMD Workbench is a browser extension for editing and previewing Mathpix Markdown (MMD) and Markdown.

## Data Processing

The extension does not collect, sell, or transmit personal data or document contents to the developer or any third party. It does not read or record the text of the web page where its panel is opened. Text that a user chooses to type or paste into the panel is processed locally in the open page so the extension can render a preview and perform user-requested copy or image-export actions. This text is held in page memory and is not saved by the extension.

The extension loads its bundled scripts, styles, and KaTeX font files from the installed extension package. It does not make network requests to a developer-controlled service.

## Permissions

- `activeTab` and `scripting` are used to open the floating panel in the current tab after the user clicks the extension toolbar button.
- `clipboardWrite` is used only when the user chooses a copy action.
- The extension exposes its bundled stylesheet and fonts to HTTP and HTTPS pages so the panel can render consistently.

## Contact

For privacy questions, open an issue in the [project repository](https://github.com/V-IOLE-T/mmd-to-markdown/issues).
